Johnson & Johnson · 2026 · Technical lead, team of five

SAVIA, a multi-agent SDLC assistant

It reads requirements from documents, recordings, and text, then recommends the SDLC agents to run on them.

I built the Python, FastAPI, and Azure OpenAI backend. Specialist agents share a base class, a registry, and one API, so adding one takes one file and one registry entry. An AI router picks the best-fit agent and backs the choice with verbatim source quotes, each checked against the input.

Outputs are grounded in the source, which removed invented names, dates, and figures, and test counts are computed in code. Requirement IDs carry through minutes → stories → design → tests, with human-in-the-loop sign-off before export.

Agentic RAG, and the evaluation around it

A production agentic RAG pipeline for customer service and cross-functional teams, in a regulated financial environment.

The pipeline does multi-step reasoning over Pinecone vector search, OpenAI embeddings, and knowledge graphs. Python and Spark pipelines feed it by unifying structured and unstructured sources across 8 financial use cases, with automated data quality checks.

Personal project · 2026 · Solo

Signal Desk, an autonomous paper-trading agent

A trading agent built on Claude Agent Skills and MCP, where every safety limit is enforced in code, not in the prompt.

It runs swing and intraday strategies with configurable approval modes and Alpaca bracket orders. Per-trade and daily loss limits, trade-count caps, and duplicate-order protection all sit in code. Before any strategy goes live it has to pass five-year historical replays.

I audited an open-source trading skill and found safety controls that existed only as prompts, then wrote nine failing tests to prove the gaps. An independent heartbeat watchdog restarted the agent within 20 seconds in crash and hang drills.
